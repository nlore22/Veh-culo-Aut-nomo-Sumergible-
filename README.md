# Vehiculo-Autonomo-Sumergible-
Diseño mecánico de un vehículo autónomo sumergible para exploración de arrecifes. Este proyecto se realizó en el Centro de Investigaciones Biológicas del Noroeste en La Paz, B.C.S

Este proyecto se centro en el diseño mecánico de un AUV así como de la elección de sus componentes electrónicos. El objetivo central del AUV es la exploración y monitoreo para el cuidado de los arrecifes en La Paz, B.C.S.
