# Vehiculo-Autonomo-Sumergible-
Diseño mecánico de un vehículo autónomo sumergible para exploración de arrecifes. Este proyecto se realizó en el Centro de Investigaciones Biológicas del Noroeste en La Paz, B.C.S

Este proyecto se centro en el diseño mecánico de un AUV así como de la elección de sus componentes electrónicos. El objetivo central del AUV es la exploración y monitoreo para el cuidado de los arrecifes en La Paz, B.C.S. 

El vehículo se inspiró en un tiburón ballena (para las aletas) y una tortuga (para el caparazón), pues se buscó que fuera lo más adaptativo para la aplicación:
![Captura de pantalla 2024-06-25 124039](https://github.com/user-attachments/assets/79b0eee9-380c-4319-b7e3-0b3073643c4d)

Las aletas se diseñaron siguiendo el patrón de Fibonacci, lo que garantizó una armonía de dimensión en el diseño:
![Captura de pantalla 2024-06-27 110105](https://github.com/user-attachments/assets/ac612e7e-319a-4151-8df0-387de6bc3710)

Se utilizaron motores brushless, pues estos motores son los más idealespara la aplicación, entre sus ventajas encontramos:
Menor mantenimiento 
Mayor durabilidad
Mejor rendimiento
Mayor control y precisión

Siendo todas las anteriores escenciales para un correcto funcionamiento debajo del agua:

![download](https://github.com/user-attachments/assets/64718d3a-0d09-4b66-ab4d-35ac93bc3af7)

Para el control, se hicieron pruebas con la tarjeta Raspberry Pi 4, esto pensando en su versatilidad, bajo consumo de energía, así cómo de la disponibilidad de puertos y usos para la IA:
